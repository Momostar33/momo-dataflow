# Momo DataFlow 使用说明

版本：0.1.0-beta.2；修改日期：2026-11-27。基于 StackRender 二次开发，来源与许可证见仓库根 NOTICE.md 和 LICENSE。

## 开始使用

按 README 运行 `npm ci`、`npm run dev`，打开 `http://127.0.0.1:4327`。点击“新建设计库”创建本地 MySQL 设计目录，或用顶部“导入设计包”导入 [虚构示例](examples/design-package-v1.example.json)。不需要真实数据库账号。导航包含表字段、字段模板、业务流程和只读关系总览；本版没有原 ERD 窗口。

## 表、字段与字段模板

表支持技术名、说明名和备注。字段模板可供新字段继承；已有字段在模板修改后先预览，再确认批量更新。金额模板固定两位小数；导入来源快照时仍保留源结构精度，不静默修改。

删除字段需要确认。有依赖时提示影响，确认后删除字段及相关业务规则、物理关系、索引关联和显示引用；取消不修改数据。依赖该字段的业务规则整条删除，避免只删一个条件后悄悄改变含义。共享字段模板和其他无关字段保留。隐藏画布字段只改变可见性，不是删除。

## 业务流程与映射

为采购、收货等业务分别建流程，每个步骤拉入相关表。同一表定义一次，跨步骤使用引用。支持开始、结束、普通步骤和判断节点；条件/触发线用于绘图说明，不是执行器。

连接两个步骤后，端点固定，右侧填写名称即可；新连线自动使用“关系1、关系2……”名称，也可自定义。连接两张表的字段后，规则限定在这两个表引用内，可补充多个条件和映射，不混入全局其他表。已有历史多表规则保留原范围。

匹配条件支持 ALL/ANY；直接映射和四则/括号公式只记录关系，不执行计算，不支持 Excel 函数。公式输入可使用“表／字段”两列选择器，也可将画布展开表里的字段拖进输入框；Mac 使用 `⌘` 点击字段插入，其他平台使用 Ctrl 点击。运算符号自行输入，来源字段按稳定 ID 保存。保存仍会检查引用和语法，错误不会静默保存成旧公式。

右侧属性面板可拖动左边界调宽或收起。删除、取消和保存位于同一操作行。

## 关系总览

总览展示已保存关系，自动布局表之间的连线，可按业务模块查看。不在总览修改表或规则；修改回到具体业务流程。自动布局不回写业务画布坐标。

## 保存、导入与设计库删除

手动保存或默认每 5 分钟自动保存，可调整间隔。设计存于当前浏览器个人资料、当前站点地址的本地 SQLite，不是按 JSON 建本地文件夹。关闭服务前先保存；清除站点数据会删除设计。请固定同一访问地址和浏览器个人资料。

导入支持文件选择，也支持把单个 JSON 拖入窗口或导入区域。文件上限 30 MiB，先预览，确认后才导入。正在处理其他对话框时，窗口拖入不会另开导入。格式见 [设计包 v1](DESIGN_PACKAGE_JSON.md)。源文件与浏览器数据不会自动同步，界面修改也不会回写文件。当前没有完整设计包导出闭环，不将 Git 当成浏览器数据备份。

v1 只追加新库，不覆盖/合并。已有同名库或 ID 冲突会拒绝。修订后重新导入时，先纳入用户修改，再生成新库名称及独立实体 ID，并重映射全部端点；只改 packageId 不足以避免冲突。公式、判断和触发线可在界面编辑，但不代表 v1 支持导入它们。

选择旧库，点击“删除设计库”，查看影响并确认。库内表、字段、业务流程、规则及直接关联一并删除；其他库和共享模板保留，源 JSON 文件不删除。存在未保存修改时先处理草稿。最后一个库也可删除，之后可新建空白库。没有回收站。

## 用于需求确认

来源快照、现有实现、精简建议和用户明确确认分开。备注说明字段粒度、来源、单位/币种、完整关联键、异常和版本。先确定权威来源，再考虑移除重复字段；分配总额和尾差不能由舍入单价反推。

确认后将业务规则回写业务项目的 spec/plan/tasks。工具文件不代替全部开发合同，也不授权模型编程或数据库迁移。重要缺项留在上游讨论。

## 常见问题

- 同名库/ID 冲突：检查是否重复导入，修订另做新版本。
- 改 JSON 页面没变化：文件不是实时存储。
- 关系缺失：检查 ref/table/field/flow 端点和类型。
- 原 SQL 类型未识别：类型说明会保留，不猜替代类型。
- 保存失败：保留草稿、查看错误，不清空站点数据重试。
- 换地址或浏览器后为空：不同来源/个人资料的数据互不自动同步。
