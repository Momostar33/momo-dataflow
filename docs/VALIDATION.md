## 依赖修补与剩余限制

最初审计有 28 项告警（2 critical、8 high、18 moderate）。本轮有意更新 Drizzle ORM 0.45.4、Vite 7.3.8、Vitest 4.1.12、@vitejs/plugin-react 4.7.0、React Router DOM 6.30.6、TypeScript ESLint 8.74.0，并修补兼容间接依赖。React 仍为 18，业务持久化结构未迁移。

两个定向 npm overrides：`@tailwindcss/typography → postcss-selector-parser 6.1.6`；`vite-plugin-top-level-await → uuid 11.1.1`。替换原因是其原依赖固定在有公告的版本；完整安装、测试、生产构建及浏览器保存已验证。后续升级父依赖时复核这两个覆盖项，不长期盲目继承。

剩余 2 项 moderate 为 react-router / react-router-dom 的关联告警，涉及 [反斜杠重定向](https://github.com/advisories/GHSA-wrjc-x8rr-h8h6) 和 [SSR 错误反序列化](https://github.com/advisories/GHSA-337j-9hxr-rhxg)。npm 给出的完整修复路径为 React Router DOM 7.18.7，属于新主版本。本版使用浏览器路由、没有 SSR，但这不等于证明所有告警均不可触发；本轮保留并披露，未自动迁移路由架构。服务默认只监听 127.0.0.1，不建议把开发/预览服务暴露到公网。
