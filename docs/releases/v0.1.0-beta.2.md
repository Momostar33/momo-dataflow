# Momo DataFlow v0.1.0-beta.2

2026-11-27 · 独立预览版，基于 StackRender 二次开发。

## 本次更新

- 字段删除增加影响确认，并清理相关业务规则、外键及索引关联。
- 字段模板命名统一，金额模板固定两位小数，移除重复的金额模板快捷按钮。
- 设计库可确认删除；设计包支持文件选择及窗口拖入，先预览后导入。
- 关系编辑限定在连接的步骤或表引用内；新关系按“关系1、关系2……”自动命名。
- 公式编辑支持拖入字段、Mac ⌘ 点击插入和表／字段两列选择；右侧属性栏可调宽、收起。
- 只读关系总览采用自动布局，不修改业务画布坐标。
- 保留独立新建设计库功能；原版 ERD 窗口不提供入口，旧路由跳转到表字段管理。
- 重写 README，明确 StackRender 来源、继承基础、二开功能与未开放能力；保留原许可、署名和原版说明快照。
- 修补依赖：Drizzle ORM 0.45.4、Vite 7.3.8、Vitest 4.1.12、React Router DOM 6.30.6，以及相关工具和定向间接依赖。业务数据结构未迁移，React 保持 18。

## 使用与升级

```sh
npm ci
npm run dev
```

访问 `http://127.0.0.1:4327`，同一浏览器个人资料和同一地址保留本版已有设计。Node 要求为 `^20.19.0 || >=22.12.0`；本次实际验证 Node 25.8.0 / npm 11.11.0。

不从其他站点来源自动迁移浏览器设计。源 JSON 与浏览器 SQLite 不同步；包 v1 只追加新库，未实现完整导出、合并或往返编辑。公式与触发仅作设计说明。清除站点数据会删除设计；删除库或字段没有回收站。

验证结果与剩余依赖告警见 [验证记录](../VALIDATION.md)。这是预览版，不等同于真实业务验收，也不包含托管部署或桌面安装包。
